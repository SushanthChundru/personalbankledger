Abstract:



The Personal Bank Ledger \&Statement Generator is a Java-based project designed to help users keep their banking transaction records in one place. Its main purpose is to make it easy to record money received, money spent, and the remaining balance. Keeping these details manually can take time and lead to calculation mistakes. This application aims to make the process simpler and more organized.



Users can enter their account details, opening balance, and transactions. Each transaction includes a date, description, amount, and type, such as a deposit or withdrawal. When money is deposited, the balance increases. When money is withdrawn, the balance decreases. The application calculates the new balance after every transaction.



The project also aims to generate a clear statement showing the opening balance, deposits, withdrawals, and closing balance. Users can review this statement to understand where their money has gone and how much remains. Showing the balance after each transaction makes it easier to follow the records and find possible entry mistakes.



The application is planned to check for incorrect entries, such as negative amounts or withdrawals greater than the available balance. File handling will help save transaction details so users can view them again later. Simple menu options will guide users through adding transactions, checking their balance, and generating statements.



This project uses Java concepts such as classes, objects, methods, conditions, loops, and file handling. It connects programming concepts with an everyday task and helps students understand how Java can solve practical problems. The expected result is an application that reduces manual work and helps users maintain clear personal financial records.
